# CreditWise Loan System

## roject Overview

CreditWise is a Machine Learning project that predicts whether a customer's loan application should be **Approved or Rejected** based on their personal, financial, and credit-related information.

The goal of this project is to help make the loan approval process faster and support better decision-making using historical loan application data.

## Dataset

The dataset contains information such as:

- Applicant and Co-applicant Income
- Employment Status
- Age and Marital Status
- Credit Score
- Existing Loans and Debt-to-Income Ratio
- Savings and Collateral Value
- Loan Amount and Loan Term
- Property Area and Education Level

The target variable is **Loan_Approved**, where the model predicts whether the loan should be approved or rejected.

## Machine Learning Models

The following Machine Learning models were used and compared:

- Logistic Regression
- K-Nearest Neighbors (KNN)
- Naive Bayes

The models were trained and evaluated to identify a suitable approach for loan approval prediction.
